# portfolio

Source of my portfolio site, live at **https://portfolio.orbital-network.com**.

It is a single static page (`index.html`) with images in `img/` and short clips in `media/`. It has no build step and no dependencies. The résumé PDF it links to is served by the live site only and is not in this repository.
